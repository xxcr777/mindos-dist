## 轻松三步

1. 安装 MindOS(约 270 MB,免安装版解压即用)
2. 首页点「新建项目」选择你的代码文件夹
3. 设置里连接一个 AI 模型(DeepSeek / OpenAI 各一个密钥,十分钟搞定),回对话输入「帮我做一个 XX」—— 开工。

> 上图即对话主界面:左边历史会话,中间 AI 干活产出,面板里有它给你生成的参考卡片。

---

## 第一步:下载安装

**系统要求**:Windows 10 / 11 64 位。

| 版本 | 说明 |
|---|---|
| `MindOS Setup 0.1.0.exe` | 安装版,一路「下一步」,可自选安装目录 |
| `MindOS-0.1.0-win.zip` | 免安装版,解压到任意文件夹,双击 `MindOS.exe` 即用 |

**下载渠道**:GitHub Releases(如果访问慢,看常见问题里的镜像说明)。

**首次启动提示(SmartScreen)**:安装包未做代码签名,(这是独立开发者的常态)Windows 在首次运行时可能提示「已保护你的电脑」——
点「更多信息」→「仍要运行」即可,仅首次。

启动后你会看到主界面。就绪状态在**标题栏**上显示(● 就绪)。

---

## 第二步:新建项目

1. 首页点「**新建项目**」
2. 选择一个**代码文件夹**(比如 `D:\my-website`)
3. 等 AI 引擎就绪(标题栏变「● 就绪」)

> 提示:项目最好放在不含空格的路径(D:\ 下直接建),遇到奇怪问题是路径解析的第一嫌疑。

---

## 第三步:连接模型并开始对话

AI 需要一个你能用的模型,任选一家:

### DeepSeek(性价比之选)
1. 打开 `platform.deepseek.com` → 注册 → 「API Keys」生成密钥(`sk-` 开头)
2. MindOS「设置 → 模型」→ 找到 DeepSeek → 填入密钥 → 连接
3. 选它作为当前模型

### OpenAI(兼容一众大厂 API)
1. 打开对应平台(OpenAI / 阿里百炼 / 硅基流动等)申请密钥
2. 设置 → 模型 → 添加服务地址 + 密钥 → 连接

<!-- ![模型连接](assets/screenshots/model.png) -->

### 开始对话
回到「对话」:
- 直接打字:**“帮我修复登录按钮的报错”**
- 发/粘贴报错信息:**“这段代码崩了:...(贴代码)”**
- 让它干重活:**“检查这个模块的安全性”**

AI 干活时:
- 需要确认的动作(改文件、执行命令)→ **审批弹窗**会请你确认(看不懂就点允许,这是正常的)
- 改完的文件在对话流里有**变更卡片**(多少行 + 文件路径)
- 有原型的效果(网页/组件)→ 对话里**直接预览**

## 权限与审批

在「设置 → 权限中心」选择谁来批准 AI 的动作:

| 模式 | 体验 | 适合 |
|---|---|---|
| **标准审批**(推荐) | 每个需要确认的操作(执行命令、改文件)弹窗询问你 | 第一次用 / 谨慎的玩家 |
| **AI 代审(信任模式)** | AI 自我评估风险,多数动作直接做,高风险仍征求你 | 熟悉的项目,想省事 |
| **完全信任** | 不再弹窗,沙箱允许范围内直接执行(越出范围的被直接拒绝) | 全自动跑批 |

> 沙箱说明:MindOS 的 AI 在受控沙箱内跑命令;写文件超出你的项目目录会被拒绝并提示。对你安全。

## Git 与拉取请求

AI 干活默认在一个**隔离工作树**里(不弄脏你的主目录)——「环境信息」按钮会显示「写隔离 / 未隔离」:

- **提交**:把当前环境的改动提交(有分支才有提交,隔离环境先「创建分支」)
- **推送**:把当前分支推到 GitHub
- **打开 PR / 创建 PR**:推送后一键创建,在 GitHub 上合并后回来看到「已完成」

> 进阶玩法:让 AI 全程接管 —— 「帮我修完 bug 再开个 PR」,它会提交、推送、创建 PR,你只负责合并。

## 自动更新

MindOS 每次**重启启动**时检查一次新版本(不发行为记录、不上传任何数据):

- 发现新版本 → 右下角提示「发现新版本 v0.2.x」
- 点「更新」→ 后台下载 → 完成提示「重启生效」
- 点「稍后」:安静,下次启动再提醒(不骚扰)

## 常见问题 FAQ

**Q:下载很慢 / 连不上 GitHub?**
国内请用镜像渠道(压缩包镜像地址见发布页评论/网盘链接),下载页面附件本身是放在 GitHub 的。

**Q:提示「没有模型」?**
设置 → 模型 → 连接模型(DeepSeek/OpenAI 任一);密钥在对应平台官网注册领取。

**Q:AI 不动 / 弹「Could not connect」?**
检查网络与代理(需要能访问你配置的模型 API 地址)。

**Q:想让我帮忙排查,日志在哪?**
`%AppData%\mindos-desktop\logs\`(把整个 logs 文件夹压缩发我,一条消息的事)。

**Q:电脑只有 8G 内存?**
能跑。别同时挂太多大项目会话;卡顿多半是同时多个任务在跑,可以等一个完成再开下一个。

## 隐私与安全

**MindOS 用一句话自证清白:**

> **100% 本地运行,绝不采集任何代码、聊天记录和文件。** 数据仅用于与你在设置中配置的 AI 服务(DeepSeek/OpenAI 等)接口交互;除此之外,没有任何遥测、埋点、上传。

- 对话内容、项目文件 **只在你的电脑上**
- 没有账号体系,你不需要注册任何 MindOS 账号
- Git 操作只在你的本地仓库 + 你授权的远程仓库

## 开发者

> 源码暂不公开分发;以下为自建 / 贡献者说明。

**技术栈**:Electron(主进程) + Vue 3 + Pinia(渲染层) + node-pty(终端) + `codex-cli 0.149.0`(AI 内核,外部进程)。

**常用命令**:

| 命令 | 用途 |
|---|---|
| `npm install` | 依赖安装 |
| `npm run dev` | 开发模式(主进程 vite-plugin-electron 构建,codex 走本机 PATH) |
| `npm test` | 全量单元测试(vitest) |
| `npm run typecheck` / `npm run lint` | vue-tsc + electron tsc |
| `npm run pack:mirror` | Windows 打包(国内镜像源,免翻墙) |
| `npm run release:win` | Windows 打包并发布 GitHub Release(打 tag 后) |

**架构**:[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) 是一份给专业读者的功能架构总览(分层拓扑、会话/审批/文件/Git 写隔离/插件/终端/生命周期各链路、任务路由与自动更新、升级纪律);实现细节见 [`docs/features/`](docs/features/),维护规则见 [`AGENTS.md`](AGENTS.md)(测试/typecheck/覆盖率红线/提交规范)。

**打包与分发**:

- 产物输出 `D:/MindOS-Dist`(与源码完全分离):安装版 exe / 免安装 zip / win-unpacked 文件夹 / latest.yml(发版上传用)
- `scripts/pre-dist-check.mjs` 打包前自动检查产物安全性(**无 sourcemap、无本机路径泄漏**)——反编译加固最小集;主进程/preload 产物经过 minify 压缩
- 镜像与网络:`ELECTRON_MIRROR` / `ELECTRON_BUILDER_BINARIES_MIRROR` 两步走已固化进 `pack:mirror`,底层 electron 依赖用本机安装避免重复下载

**许可证与署名**:

MindOS Desktop 使用 [openai/codex](https://github.com/openai/codex)(Apache-2.0)官方构建产物 `codex-cli 0.149.0` 作为独立外部进程集成,经 app-server 协议通信;**未修改、未派生其任何源码**;适配层(protocol/IPC/渲染层)为 MindOS 自有原创代码。所有权与署名归 OpenAI 及其 codex 项目贡献者所有,详见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) 第 5 节。
