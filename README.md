## 下载安装

| 文件 | 说明 |
|---|---|
| `MindOS Setup 0.1.0.exe` | 安装版(推荐) —— 一路下一步,可选安装目录 |
| `MindOS-0.1.0-win.zip` | 免安装版 —— 解压到任意目录,双击 `MindOS.exe` |

> **版本 v0.1.0** · 系统要求:Windows 10/11 64 位。首次运行 SmartScreen 提示时点「更多信息 → 仍要运行」。

## 快速开始(三步)

1. 安装 MindOS(或解压免安装版)
2. 首页 → **新建项目** → 选择代码文件夹
3. 设置 → **模型** → 连接一个模型(DeepSeek / OpenAI 兼容),回对话输入需求开始

更多使用说明(配图版)见主仓库 [README](https://github.com/xxcr777/mindos-desktop)。
